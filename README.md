# Adventure with Makeda — website

The Makeda Multiverse: the family-facing home for Adventure with Makeda.
Static HTML/CSS/JS + PWA, deployed with GitHub Pages. No build step and no dependencies.

- `index.html`, `story.html`, `world.html`, `parents.html` — the four pages
- `styles.css` — design system and candy layer
- `site.js` — menu, reveals, world map trail, world cards, sparkles
- `sw.js` + `manifest.json` — offline shell / installable PWA (bump `CACHE` in `sw.js` when assets change)
- `assets/` — optimized WebP art (book covers, cameos, medallions, decor, logo)

Preview locally: `python3 -m http.server 5178` and open http://127.0.0.1:5178

The pages are generated by `~/makeda/web/sites/build_v1.py`, which keeps the shared header and footer consistent across all four.
